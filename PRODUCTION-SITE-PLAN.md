# The Production Site — cashdublo.com, in segments

The President's decision, 2026-11-20: the production site is **cashdublo.com**,
built clean and **segmented by job** — not a copy of this GitHub Pages site.
This website (BigOdom1984.github.io) stays as the **link hub and workshop**:
it links to the already-built front ends and the back end, each with its true
state, and it holds the seats' folders and experiments.

## The segments

- **cashdublo.com** — the storefront. The public face: the shelf of apps,
  each app's page, the company pages. Nothing on it that a record cannot back.
- **The store segment** — the CashDublo App Store's web face, reading the
  server's shelf (the catalog door). It takes its place when the store doors
  switch on.
- **The back end** — the CashDublo Server. The President updates the server
  himself from the BigOdom1984 repositories; new layouts are built with the
  server's API. The App Store doors (catalog, package pieces, master ledger)
  are built and proven in the server record and switch on with that update.
- **The course segment** — the online course's production face, at the
  production address named in the course record, when it goes live.
- **The web apps** — each app's web face takes its own segment or address
  when it wakes. Travel Journal Web wakes when its three deploy keys are set;
  the others take their addresses as the server round reaches them.

## The rules

- **One source of truth.** Every segment is built or checked from the
  repository records — a version, a price, or a state that no record backs
  does not ship. The midnight check holds every segment to the records.
- **Links only where live.** The hub links a door only when it is truly live.
  Built-but-sleeping pieces are named with their true state, never dressed up.
- **One design system.** All segments share the house navigation standard and
  the theme family, so the whole domain reads as one company.
- **The split of hands.** The server update and the new layouts are the
  President's own round, on his server, with his API. The hub, this plan, and
  the nightly check are the General's desk.
