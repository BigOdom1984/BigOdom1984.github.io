Build Manager

SOURCE: MAC 0.1.0

Builds every CashDublo app from one place: pick an app or build them all, watch the log, and see what got built.

What it does

  • Lists every app that carries build scripts — the phone apps and the desktop tools — each with the version read from the app itself
  • Runs the app's own build script in its own folder — Build, Demo, Licensed, Update or Pull — and shows the run live in the log pane
  • Build Changed Apps and Build Every App run the whole shelf from the same window
  • Every run ends with a plain summary: built OK, or failed with the script's own last error line
  • What it reports comes only from real evidence — the build markers the scripts write and the runs it drove itself. Nothing is guessed

Why have it

the whole shelf builds from one window, and the log never pretends.
