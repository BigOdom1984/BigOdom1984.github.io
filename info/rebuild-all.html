Rebuild-All

Version: 0.1.0

Keeps every CashDublo repo safe — and can bring them all back. It checks the repo count, builds the whole AI Coding folder, makes the smallest full backup, and rebuilds everything from that backup.

What it does

  • Repo check at launch: counts the repos it can see and compares the count with the count it has stored
  • Build the AI Coding folder: clones every repo that has no folder yet, in the foreground or in the background with a log
  • Make the smallest backup: one git bundle per repo, zipped into a single RebuildAll backup file
  • Rebuild from backup: pick a backup file and every repo in it is cloned back and given a quick health check

Why have it

if the computer or the folder is ever lost, the whole shelf comes back from one file.
