Script-Run

SOURCE: MAC 0.2.0

A small Mac app that lists every build script in its folder, each with a plain line on what it does. You pick one, and the app runs it and shows the run in its own terminal pane.

What it does

  • Each script listed once: a script and its GUI twin are one line in the list, marked GUI — and the frozen backup copy gets its own line, marked FROZEN, shown so it is accounted for and never run
  • The full "what it does" line for the script you pick is shown under the list, read from the comment at the top of the script file itself — a script with no line of its own shows its file name instead; nothing is made up
  • Run with the button, a double-click, or Enter; when a script asks a question mid-run, type the answer in the row under the pane
  • If the script has a GUI version, the app asks first: its own windows, or the plain script in the pane inside the app
  • The Terminal guide button explains, in plain words, how running a script inside the app works
  • Update scripts pulls the scripts folder fresh from GitHub inside the app — your changed files are saved into an old-saves folder first, so nothing is lost — and stale GUI apps are built fresh after
  • Build GUI apps makes the folder's little window apps and keeps a copy in your Applications folder

Why have it

no more hunting through the scripts folder in Finder — every script, what it does, and its run, all in one window.
