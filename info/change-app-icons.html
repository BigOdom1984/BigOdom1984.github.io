Change App Icons

SOURCE: MAC & WINDOWS 1.0.0

A window program for Mac and Windows that shows every app in your GitHub repos with its name, its description, and every icon the repo uses — each at the size it is really used at. Pick a new picture to change an icon, or bring an old one back.

What it does

  • The new picture must be a real PNG or JPEG and the exact same size as the icon it replaces — the program never resizes or stretches
  • Before any change, the old icon is saved into a backup file — no backup, no change
  • After sending, the program reads the icon back from GitHub and compares it; if it does not match, the original is put back on its own
  • If the file on GitHub changed since the scan, the program stops instead of overwriting it
  • The last 5 icons for each icon spot are kept — as single files you can restore with one button, and inside that spot's own archive file
  • Two rolling logs live with the program: every change ever made, and every problem, in plain words
  • Sign-in is a GitHub token you paste once; it never leaves your computer except to GitHub

Why have it

change an app's icon with the risk taken out — backed up first, read back and checked after, and undone on its own if the change does not take.
