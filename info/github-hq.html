GitHub HQ

MAC 0.1.0

The home screen for your GitHub repos. It opens on your account and lists every repo you own — there is no account picker, no feed, and no explore page: your repos are the home page.

What it does

  • Every row shows the repo name, private or public, its description, the last push, its version, the state of the copy on this Mac, which build scripts it has, and its newest finished build — or "No builds yet" when there is none
  • Anything GitHub cannot say is shown as a dash — nothing is guessed or filled in
  • Pull updates a repo under the nothing-lost rules: local changes are copied into the old-saves folder first, then the folder is synced to GitHub
  • Clone brings a missing repo down to your computer
  • Build runs the repo's own build script, live in the log pane — and when a script asks a question, you type the answer in the row under the pane
  • Pull All updates every repo folder in one run; Stop asks a build to stop gently, and a second click always forces it closed
  • When the sign-in is missing or is a different account, the app says so at the top, prints the exact fix steps, and shows the local folders only

Why have it

every repo, its version and its newest build on one screen — pull, clone and build without opening anything else.
