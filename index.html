About Me

I'm Greg Odom, an independent app developer. CashDublo is my one-person app company, and I design and build every app myself - from the first sketch to the finished release.

Before apps, I served in the United States Air Force, and I'm a disabled veteran. These days I live and travel in Southeast Asia - Cambodia is home base right now - and I build my apps for the people around me here: Cambodia, Laos, Thailand and the wider region. Every CashDublo app is built to speak Khmer, Lao and Thai, not just English.

When I'm not writing code, I'm making music - I record as Big Odom.

Tools I Build With

React Native Expo TypeScript Python GitHub

Phone apps in React Native and TypeScript with Expo. Desktop tools in Python. Every line of code kept on GitHub.

And these are my own build tools - the programs and scripts I made to build the apps with:

GitHub HQ

The home screen for your GitHub repos: every repo with its version, its build scripts and its newest finished build - pull, clone and build from one place.

Build Manager

Builds every CashDublo app from one place: pick an app or build them all, watch the run live, and see what got built - from real build records, never guesses.

Rebuild-All

Keeps every CashDublo repo safe: one small backup file holds the whole set, and the rebuild brings every repo back with only the program and the backup - no GitHub, no sign-in, no internet.

Script-Run

Lists your build scripts in one window, each with a plain line on what it does, and runs the one you pick.

App Translator

Turns the CashDublo apps into other languages - Khmer, Lao and Thai first: one AI translates each line, a second AI checks it by translating it back, and only lines that pass are shipped.

CashDublo Coder

A coding helper that runs on your own computer: ask the AI that lives on your machine, browse your GitHub repos, and jump to the docs and forums that help you build.

Change App Icons

Swap an app's icon on GitHub, with a backup saved first so you can undo it - then it reads the icon back to prove the change took.

Build Scripts

The script family that builds and installs the apps: build one app or every app, send the finished apps to the phone, and keep the scripts themselves up to date from GitHub.
