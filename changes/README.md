# Website Change Control

This folder is the website repository's dedicated change-management section. It records changes to this website only: HTML, CSS, JavaScript, assets, copy, navigation, accessibility, SEO, and GitHub Pages configuration.

It is independent of the CashDublo-wide change store. The canonical cross-repository master change log, AI assignments, approvals, and governance live in **[AI2AISync](https://github.com/BigOdom1984/ai2aisync)**. Temporary proposed files and patches for cross-repository work belong in the private **`BigOdom1984/changes`** repository when that repository is created.

## Files in this section

- [CHANGE-LOG.md](CHANGE-LOG.md) — append-only website change history.
- [AI-ACCOUNTABILITY.md](AI-ACCOUNTABILITY.md) — contributor identity, evidence, review, and multi-AI collaboration rules.
- [TEMPLATE.md](TEMPLATE.md) — required entry format for every website change.

## Scope and privacy

This GitHub Pages repository is public. Never place credentials, tokens, private user data, internal AI conversations, private repository code, or confidential security details here. Record only public-safe summaries and links. Keep sensitive evidence in an appropriately private location and link it only where access is authorized.

A record in this folder documents a website change; it does not replace AI2AISync's central task record or approvals. A proposed change is not an applied change, and a commit is not proof that the website was visually or functionally verified.
