Command tools are grouped separately from ordinary desktop apps. Each entry shows its verified platforms, capabilities, version and release status.

Secure Mac Remote Terminal

Version: Not tagged / verifyStatus: In development / release verification requiredCategory: Command ToolPlatforms: macOS · Android companionCapabilities: SSH · SFTP · Port forwarding

A native macOS SSH terminal with a full terminal emulator, strict host-key verification, SFTP and local port forwarding, plus an Android companion console. The project README states that Windows, Linux and iOS are not current targets. The Android console is not yet feature-equivalent to the macOS terminal emulator.

All Apps listing ↗

Release note: the repository reports that the macOS bundle is unsigned and not notarized, hands-on testing remains, and the project has not had an independent security audit. Do not treat it as a security-certified product.
